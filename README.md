# Swaraj Agro Website — Fresh Public Design

This version keeps the existing Express backend, MongoDB/Cloudinary integration, admin login, password reset, product management, branches and photo management intact.

Only the public-facing website presentation and public page templates have been rebuilt to closely match the supplied Swaraj Agro homepage design concept: large hero photography, spacious typography, green/cream palette, trust stats, two business cards, featured photos, authorization strip and compact dark footer.

## Important
Do not replace your production Render environment variables. They remain outside this ZIP.

For an existing GitHub/Render deployment, replace the project source with this ZIP's contents, preserving your environment variables and MongoDB data.

The existing admin views were intentionally left unchanged.
